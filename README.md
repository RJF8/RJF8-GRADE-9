# RJF8 GRADE 9

سامانهٔ آموزشی فارسی و راست‌چین پایهٔ نهم با Supabase.

## امکانات فعلی

- داشبورد و ۱۱ حوزهٔ درسی
- جست‌وجو و فهرست درس‌نامه‌ها
- مطالعهٔ درس، آزمون چندگزینه‌ای و تصحیح پاسخ در سمت سرور
- ثبت نتیجه، XP و مسیر پیشرفت
- ورود و ثبت‌نام ایمیلی، خروج از حساب و وضعیت نشست
- تم روشن/تیره با ذخیرهٔ انتخاب کاربر
- رابط واکنش‌گرا و منوی موبایل

## اصلاحات فنی اخیر

- بارگذاری Supabase JS به‌صورت غیرمسدودکننده؛ داشبورد پیش از دریافت کتابخانه و داده‌های سرور نمایش داده می‌شود.
- بارگذاری CSS فونت به‌صورت غیرمسدودکننده با fallback سیستم.
- حذف همگام‌سازی تکراری نشست و درخواست‌های غیرضروری upsert پروفایل.
- واکنش به رویدادهای Auth برای ورود/خروج و به‌روزرسانی رابط.
- کش سمت کاربر برای فهرست درس‌ها، جزئیات درس، فهرست آزمون و پرسش‌ها.
- دریافت هم‌زمان محتوای درس و آزمون مربوط، به‌جای درخواست‌های ترتیبی.
- محدود کردن ستون‌ها و تعداد ردیف‌های درخواست پیشرفت.
- افزودن ایندکس برای فهرست آزمون‌های منتشرشده.
- بهینه‌سازی سیاست‌های RLS برای جلوگیری از ارزیابی تکراری اطلاعات نقش کاربر و حذف هم‌پوشانی سیاست‌های خواندن/مدیریت در جداول اصلی آموزشی.

## محتوای فعلی

- ۱۱ حوزهٔ درسی
- ۲۲ درس‌نامهٔ آغازین
- ۲۲ آزمون
